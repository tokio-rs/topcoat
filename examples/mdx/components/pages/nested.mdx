# Nested Components

Demonstrates nesting components inside each other. A Wrapper contains a Callout containing text.

<Wrapper>
<Callout var="info">
This callout is nested inside a wrapper component. Components can be composed to build complex layouts.
</Callout>

## Nested heading

You can also have regular markdown content alongside nested components.

<Callout var="warning">
Another callout inside the same wrapper.
</Callout>
</Wrapper>
