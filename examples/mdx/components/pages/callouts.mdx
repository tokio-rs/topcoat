# Callouts

Demonstrates the Callout component with different `var` attribute values.

<Callout var="info">
This is an informational callout. It provides helpful context about the current topic.
</Callout>

<Callout var="warning">
Warning: this action cannot be undone. Please proceed with caution.
</Callout>

<Callout var="error">
Error: something went wrong. Check the logs for more details.
</Callout>
