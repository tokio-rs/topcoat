# Feature round-up

A round-up of what `topcoat-mdx` can do, written as a post so the blog has something to list.

## What's new

- **`compile_mdx!`**: compile MDX files at build time
- **`mdx_pages!`**: auto-discover and register a directory of MDX files as routes
- **Frontmatter extraction**: read `title`, `date`, `excerpt`, and `tags` into a compile-time content index
- **Component embedding**: embed Topcoat components directly in MDX
