# Footnotes

MDX supports footnotes, which let you add references without cluttering the main text. Here is a sentence with a footnote.[^1] You can have multiple footnotes in a single paragraph[^2] and they render as numbered links.

Footnotes are especially useful in technical documentation where you need to provide additional context[^3] without breaking the reader's flow.

[^1]: This is the first footnote. It provides additional detail about footnotes in MDX.
[^2]: This is the second footnote. Footnotes are rendered as superscript numbers by the MDX processor.
[^3]: This is the third footnote. They appear at the bottom of the document by default.
