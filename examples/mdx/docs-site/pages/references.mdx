# Reference Links

Markdown supports reference-style links, which keep your prose clean while defining URLs separately.

Topcoat is a full-stack web framework built with Rust. You can find it on [GitHub][repo] or learn more about the language itself at [Rust][rust]. The shorthand form works too: [rust].

Definitions live at the bottom of the file and never render. The walker collects them in a first pass, so a reference can appear before the definition it points at.
