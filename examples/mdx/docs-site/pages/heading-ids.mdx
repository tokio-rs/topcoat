# Heading IDs

Headings in MDX automatically receive `id` attributes based on their text content. This enables direct linking to sections within a page.

## Getting Started

The heading above gets the id `getting-started`. You can link directly to it using `#getting-started`.

## Configuration

Configuration options are typically documented under their own heading. This one gets id `configuration`.

### Basic Settings

Nested headings work the same way. This section receives id `basic-settings`.

### Advanced Options

You can also have sibling headings at the same level. This one gets id `advanced-options`.

#### Troubleshooting

Deeply nested headings like this one get id `troubleshooting`.

Auto-generated IDs use kebab-case formatting, so "Getting Started" becomes `getting-started`.
