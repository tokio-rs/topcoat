# Typed Metadata

This post declares seven frontmatter fields. Four of them have named slots on the index entry; the other three would be lost without a type to read them into.

Passing `frontmatter = BlogPostMeta` to `mdx_pages!` gives every entry a `meta()` that answers with the whole struct. The layout around this page reads the subtitle, the author, and both dates from it, none of which appear in the body you are reading.

Deserializing happens once per page, on first read, rather than on every request.
