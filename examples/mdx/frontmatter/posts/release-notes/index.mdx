# Release Notes

This file is `posts/release-notes/index.mdx` and serves `/blog/release-notes`. Without the rule the route would end in a repeated segment.

A directory per post is worth having when a post owns more than its text: images, partials, or a translation sit next to it, and deleting the directory removes the whole post. The flat files alongside this one still work exactly as before.
